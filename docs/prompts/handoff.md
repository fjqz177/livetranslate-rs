1. 看板同步：AGENTS §8 三小节反映真实现状——完活的删行、新遗留的加一行指针、新待拍板的入册。
2. 项目记忆：新的长期事实（用户裁决/踩坑/工作方式）写或更新 memory 文件 + MEMORY.md 索引行；
   相对日期换算为绝对日期。项目记忆存于仓外 ZCode 工作区（~/.zcode），不在本仓库内。
3. 未了项：走查/待裁决一律登记 §8，别只留在会话记忆里。
4. 工作区：git status 干净，或明确说明未提交物是什么、为什么（drafts 除外——本就不入库）。
5. 下一步：留一句话锚点给下一个会话（当前进行到哪、下一步做什么）。
