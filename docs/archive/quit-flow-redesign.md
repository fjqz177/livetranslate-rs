## 一、现状取证（病根，全部实锤）

退出入口共两处：悬浮窗顶栏「退出」红钮、托盘菜单「退出」。所有窗口 X = 隐藏不退出（`app.rs:2386`，「关窗=隐藏、退出只走托盘」，本方案不动此语义）。

1. **弹设置界面的根因**：确认框是 egui 帧内模态（D-33/H-3，规避 rfd 同步 MessageBox 阻塞事件循环——G-14 仍有效），只能借已有窗口当画布。宿主选择（`state.rs:2500`）：悬浮窗可用 → 悬浮窗；否则 → 面板，且**面板隐藏时被强制拉起**（`app.rs:511`）；取消再 `HidePanel` 藏回（`confirm.rs:59` → `app.rs:1600`）。
2. **巨大空白根因**：egui `Window` 默认尺寸 340×420（egui 0.36.1 `default_size([340.0, 420.0])`），`confirm.rs:34` 只改宽 380、高度继承 420；内容仅 ~100px → 空心 300px。
3. **透明幽灵体根因**：悬浮窗宿主时模态无不透明底 → 壁纸透出；面板宿主时主题跟面板走（用户浅色主题 = 白框）。
4. **全场景陷阱**（第二轮取证）：
   - 托盘在 `app.rs:168` 事件循环前即建 → 启动向导期托盘退出也凭空拉面板叠窗；
   - **退出丢设置——原判定过重（施工核实，见 §八.1）**：面板多数编辑直写 `ui.app_state.settings`，`shell.shutdown()`（`shell.rs:183`）存该对象即全量兜底；仅 cmd 载荷独占变更（SetAsrLanguage/SetPadding/IncrementalAsr/SetTargetLanguage/SwitchEngine，`shell.rs:35`）存在「最后一帧未消化即退出」的极窄丢失窗口，与原版同级；
   - **窗口位置同样防抖 500ms**（`TickKind::PosSave`，`app.rs:2495`）→ 拖完悬浮窗半秒内退出位置白拖；
   - 宿主被藏 → 模态态残留 → 后续退出被幂等静默忽略（退出假死）；
   - 其他确认开着 → 退出被单槽互斥静默忽略（界面零反馈）；
   - Enter/ESC 未接线；
   - compact 24px 矮条上退出钮仍显示（`overlay.rs` 行1），egui 模态画不出窗口矩形 → 几何不可达，此为「紧凑→借面板」由来。
5. **收尾链本身健全**（`main.rs:115` INV4 + `shell.rs:176` stop 管道 + save settings + Job Object 收割 worker）——病在确认框与防抖，不在收尾，本方案不动收尾链结构。

## 二、决策史（留痕，v1 → v3.2）

| 版本 | 主张 | 结局 |
|---|---|---|
| v1 | 专用 Confirm 窗 + 托盘保留确认 + 固定暗色 | 被八原则自审部分推翻：托盘改直退后专用窗失去客户；固定暗色判为拍脑袋 |
| v2 | 托盘直退 + 悬浮窗长按退出（零弹窗）+ 就地修五确认 | **用户裁决推翻**：「托盘退出也要弹窗防误触」 |
| v3 | 专用窗回归包办六确认 + 长按废止 | 八原则 review 审出 2×P1 / 2×P2 / 2×P3 → v3.1 修正 |
| v3.1 | + 替换语义 + 身份键载荷 + 全量冲刷 + 属主遮罩 | **用户裁决**：范围六确认全做；确认窗要 egui 原生、主界面质感（圆角/半透明） |
| **v3.2** | 视觉定稿：固定暗色半透明 + 圆角自绘（推翻 v3.1 的「原生标题栏」与「跟随面板主题」两点） | **本稿** |

长按废止理由（留痕）：其核心论据「compact 几何无解」被专用独立窗消灭；用户明确偏好弹窗防误触范式。
固定暗色理由（留痕）：用户点名「类似主界面的样式」——主界面质感即暗色半透明；跟随浅色面板反而重现「白框」投诉面。
TaskDialog 另线程再议仍弃：系统浅色框与暗色应用恒割裂 + G-14 线程管线 + 按钮本地化成本。

## 三、最终设计

### 3.1 语义层（入口 × 行为）

| 入口 | 现状 | v3.2 |
|---|---|---|
| 托盘「退出」 | 确认框（全隐藏时凭空拉面板） | **弹确认窗**，光标所在屏工作区居中；确定/取消/X/ESC 收敛，全程不动任何窗口可见性 |
| 悬浮窗「退出」钮（full / compact） | full=透明空心框；compact=凭空拉面板 | **弹同一确认窗**，悬浮窗所在屏居中（独立原生窗不受悬浮窗矩形裁剪，compact 几何问题消灭） |
| 面板五种内容确认 | 同一空心框宿主于面板 | **弹同一确认窗**，面板窗口居中 |
| 窗口 X / Alt+F4 / 任务栏关闭 | 隐藏不退出 | 不动（字幕窗 X 额外关字幕） |
| 启动流缺模型下载失败点「关闭」 | 直退免确认 | 不动 |
| 退出收尾 | 丢 300ms 设置 / 500ms 位置 | **先冲刷全部待落盘防抖再 exit**，其余收尾链不动 |

### 3.2 架构

- **`WinId::Confirm` 第七窗**（lt-ui 内部枚举非契约）：`create_window` 基建同款，启动即建、常驻隐藏；无边框自绘（见 3.3）。
- **状态机迁入**：`request_confirm` 签名简化为 `(kind, title, msg)`——砍掉 `overlay_ok` / `panel_visible` 参数与宿主匹配渲染；新增 **replace 语义**（Quit 请求可替换在开确认——未收敛确认无副作用，替换安全；保证退出永远有可见反馈，消灭单槽静默忽略陷阱）。
- **`ConfirmKind::DeleteModel` 载荷改身份键**：`index: usize`（`state.rs:278`）→ `(engine, name)`（与缓存探测同键）；应用时按键查行，查不到（列表已变）→ 静默取消 + debug 日志（fail-safe，杜绝删错行）。
- **杂技链整删**：`overlay_can_host_confirm`、`panel_shown_for_confirm`、`WinAction::HidePanel` + 处理器、ShowPanel 补偿调用——确认窗永不改变任何窗口可见性。
- **新增 `WinAction::ShowConfirm`**：UI 按钮点击 → 意图通道 → 宿主显窗（WinAction 通道既有模式，非契约）。
- **属主遮罩（真模态）**：确认期间属主窗口（面板/悬浮窗）盖全窗遮罩层——微暗（黑 ~35%）+ `Sense::click` 吞点击（~5 行）；确认关闭自动解除。原生对话框本就禁用属主，此为对齐。
- **定位**：托盘触发 → 光标所在屏工作区居中（复用字幕窗 ScreenZone 基建）；属主触发 → 属主窗口几何中心；一律 `clamp_to_screen` 防出屏。
- **置顶**：弹出时 topmost（悬浮窗置顶只在创建/显隐/事件点重申（`app.rs:181`），非每帧，冲突面小；实机验证项）。
- **退出冲刷——经核实不做（施工修正）**：位置防抖（`PosSave` 500ms）与设置防抖的落点都是 `ui.app_state.settings`，退出时 `shell.shutdown()` 全量保存已兜底；为理论边角新增退出时序复杂度不值得，砍除（§八.1）。

### 3.3 视觉规格（用户授权审美定稿；内容纯 egui 绘制，零 Win32 控件）

```
        ╭───────────────────────────────────────╮
        │  ● 退出 LiveTranslate              ✕  │   ← 自绘标题行：语义色圆点 + 15pt 标题 + 关闭钮
        │                                       │     整窗圆角 12px，1px 描边，悬浮窗同款材质
        │   确定要退出吗？                       │   ← 正文 13pt 主文本色，内嵌三字体
        │   正在进行的翻译将被停止。              │
        │                  ┌────────┐ ┌────────┐│
        │                  │  取消  │ │  退 出  ││   ← 按钮右下：主钮实底语义色、次钮描边幽灵款
        ╰───────────────────────────────────────╯      高 30px、圆角 6px、悬停增亮、按下微沉
```

- **材质**：无边框；整窗 LAYERED + LWA_ALPHA **0.95**（比悬浮窗略实——对话框要读要判）；底色**取悬浮窗现行体内色常量同源**（本文不另立色值，避免两处真源）；圆角 **12px** 用 SetWindowRgn 裁区（悬浮窗已验证同款，不搞 Win11 DWM 分支——如无必要勿增实体）；1px 描边同悬浮窗 stroke；**不做外阴影**（wgpu HWND 逐像素透明不可达，D-36 已证），靠描边+半透明自然浮起。G-15 自愈重挂复用悬浮窗现成模式。
- **布局**：宽固定 **380 逻辑 px**；高内容自适应（约 150~190px，**永别 420 空心**）；标题行高 ~36px 兼拖动区；按钮行右下。
- **语义色（全部复用现有调色板，零新增颜色）**：退出 / 删模型 / 删全部 → 主钮**红**（与悬浮窗红底退出钮同色，点了什么确认什么）+ 标题行红点；恢复默认 / 清空记录 → 主钮中性亮灰填充；取消恒为描边幽灵钮。
- **主钮文案 = 后果动词**（不写「确定」）：退出 / 删除 / 恢复默认 / 清空——眼睛不用上移核对；i18n 新键 **zh/en 两份 yaml 同步**（键集一致纪律）。
- **动效**：入场 120ms 缩放 0.97→1 + 淡入（复用 toggle_mode 200ms 动画的现成节拍调度，G-1 纪律：有限重绘不进循环）；`reduce_motion` 开启直切。
- **拖动——施工砍除（§八.2）**：短命模态居中呈现、无位置保存需求；G-17 SetCapture 管线为常驻窗设计，为秒级对话框引入不值，如需后补另立案。
- **字体**：内嵌三件套（D-17），零新增资产。

### 3.4 交互收敛

- **Enter = 主钮；ESC = X = 取消**（补齐现状缺口）。
- 托盘重复退出幂等（窗已开即忽略——窗可见，无死端）。
- 确认窗关闭后焦点归还依赖 Windows 默认 Z 序（实机验证项）。

## 五、实机走查矩阵（S4 验收单）

- 托盘退出 ×｛运行 / 暂停 / 启动向导期 / 模型下载中 / 全窗口隐藏｝：窗弹光标屏居中；确定→退（含向导期）；取消/X/ESC→散，无任何窗口被开合。
- 悬浮窗 full / compact × 退出钮：窗弹悬浮窗屏居中；**compact 不再拉面板**。
- 面板五确认：各自弹窗居中面板、语义色正确、遮罩生效（确认期间面板点不动）、取消无副作用。
- 替换语义：删模型确认开着 → 托盘退出 → 框替换为退出确认，无静默。
- 幂等：退出框开着再点托盘退出 → 不叠加。
- 删模型身份键：确认开着时下载完成入列新模型 → 确定后删的是确认时那一个（或 fail-safe 取消），绝不删错行。
- 退出保存：改设置（含语言/引擎下拉）后立即退出 → 重启后生效；拖悬浮窗后立即退出 → 位置保留。
- Z 序：确认窗开着切换悬浮窗显隐不互压；关闭后焦点归还正常。
- 多屏：光标屏居中；贴边属主居中不出屏（clamp）。
- 主题：浅色面板下确认窗恒暗色；reduce_motion 开启动效直切。
- 无边框拖动确认窗；Win10 圆角裁区边缘观感可接受。
- 全量：604+9 绿基线滚动 + clippy 0 + precommit 七项。

## 六、风险与不自信点（诚实清单）

1. **置顶互压**：确认窗与悬浮窗均为 topmost，悬浮窗在显隐/事件点重申层级——理论冲突面小，实机验证；兜底 = 确认窗弹出时序上后置 + 必要时延迟 1 帧再 raise。
2. **焦点归还**：确认窗关闭后焦点去向依赖 Windows 默认行为，实机确认；异常时显式 raise 属主。
3. ~~quit 冲刷时序~~ 已消除：经核实 UI 直写 settings、shutdown 全量兜底，冲刷机制不做（§八.1）。
4. **圆角裁区抗锯齿缺失**（Win10 SetWindowRgn 硬边）：半径 12px 下预期可接受（悬浮窗已验证同路径）；实机观感不过关则降半径或改直角+描边。
5. **屏蔽层与列表竞态**：身份键兜底后仍需测试覆盖（下载完成恰落确认期间）。
6. ThemeMode 默认 Dark（`state.rs:1499`）、用户当前 Light——确认窗恒暗为定稿决定，若实机观感不佳回退开关 = 一行改常量。

## 七、明确不做（消融留痕）

- 关窗=隐藏语义、字幕窗 X 关字幕、启动流失败直退——不动。
- WM_ENDSESSION 关机钩子——不做（收益仅防抖窗口内数据，Windows 5s 强杀兜底，shutdown join 反有超时险）。
- 退出后 toast / 气泡——不做（消失即反馈，主流惯例）。
- 「不再询问」记忆选项——不做（过度设计）。
- 长按退出——废止（决策史 §二）。

## 八、施工留痕（定稿后偏差，随实现 commit 登记）

1. **退出冲刷机制不做**（修正 v3.1 的 P2-3 判定）：核实 `apply_settings_side_effects`（`shell.rs:35`）——面板页编辑直写 `ui.app_state.settings`，`shell.shutdown()` 全量保存兜底，防抖节拍只管热应用与持久化时机，「300ms 内改动丢失」不成立；仅 cmd 载荷独占变更（SetAsrLanguage 等 5 键）存在最后一帧丢失窗口，与原版同级，本包不修。
2. **确认窗拖动砍除**（v3.2 §3.3 曾承诺）：G-17 SetCapture 管线为常驻窗设计（drag state + 每帧推进 + ReleaseCapture 全链），短命模态不值，如需后补另立案。
3. **悬浮窗穿透豁免删除**：D-33/H-4 的「确认模态开在悬浮窗上时强制非穿透」随去宿主化整删——确认窗独立原生窗，不受悬浮窗 WS_EX_TRANSPARENT 影响。
4. **托盘分隔线已存在**（`build_inner`），原 S2 该项零改动。
5. **窗高定稿 160 逻辑 px**（§3.3 曾写「150~190 自适应」）：独立原生窗无内容自适应，按最长三行文案（en 恢复翻译页）定 160 固定值；单行留白 ~35px 为呼吸感非空心。
6. **入场动效降为纯淡入**（§3.3 曾写缩放+淡入）：egui 全窗坐标系下缩放需重排全部图元，收益低；`set_opacity` 120ms 淡入 + `reduce_motion` 直切已达标。

## 九、实机走查留痕（完工收口，2026-09-14）

**已验（用户实测，三轮视觉迭代 + 行为修复收敛）**：
- 确认窗视觉：初版空心/透明/白框 → 定稿样式；正文缩进漂移（流式排版落点漂移）→ 显式矩形 `new_child` 布局（各行锚定、左右 20px 恒定）；壁纸透出过强 → LWA_ALPHA 242→250；顶缘高光白线（用户否）→ 删除；层次感 → 底色提亮/标题分隔线/文字三级对比/主钮描边/按钮 32px；
- 圆角马赛克毛边 → 根因 = SetWindowRgn 1-bit 硬裁剪切过 egui AA 渐变带；修法 = 体填充分 r=6（裁刀切纯色，余量 ≈2.5px）+ 裁区曲线内侧 2px rim（`FILL_RADIUS`/`RIM_STROKE`）；
- 置顶互压（点击悬浮窗盖住弹窗）→ `Focused` 重抬 + `SWP_NOACTIVATE`（`ensure_confirm_on_top`，§六.1 闭合）。

**遗留走查（§五矩阵其余行为项，随用随验不拦归档）**：托盘×｛向导/下载中/全隐藏｝退出、面板五确认回归、替换语义/幂等实点、删模型身份键失效路径、多屏光标屏居中、reduce_motion 直切。验出问题按矩阵对照修，本档归档后仅许修订注记。
